📖 How to Update Your Site

1. Load your current data.json (from your repo or local file)
2. Make changes using the form above or edit the raw JSON
3. Click "Export data.json" to download the updated file
4. Replace the data.json in your GitHub repo and commit
5. GitHub Pages will automatically serve the new data

Tip: Keep a backup of data.json before making changes.
